# 14 – Gamification

## Ziel

Gamification soll die langfristige Nutzung fördern, ohne den Second-Screen-Kern zu überladen.

## Elemente

- Erfahrungspunkte (XP).
- Mitwisser-Level.
- Ranglisten.
- Badges.
- tägliche Herausforderungen.
- Wochenziele.
- persönliche Bestleistungen.

## XP-Quellen

| Aktion | XP-Idee |
|---|---|
| Live-Abstimmung abgeben | kleine XP-Menge |
| Chat-Kommentar schreiben | kleine XP-Menge, Rate Limit beachten |
| Emoji-Reaktion senden | sehr kleine XP-Menge oder keine XP gegen Spam |
| Quiz abschließen | abhängig von Ergebnis |
| Memory abschließen | abhängig von Schwierigkeit, Zeit und Zügen |
| vollständiger Live-Abend | Bonus-XP |
| Badge freischalten | Bonus-XP |

## Level

Level steigen visuell von Grau über Blau zu Gold.

## Badges

Beispiele:

- Fan der ersten Stunde.
- Spurensicherung.
- Mitwisser der Extraklasse.
- Serienrätsler:in.
- Quiz-Profi.
- Memory-Meister:in.
- Live dabei.
- Kommentar-König:in.

## Quiz

### Standard

- 15 zufällige Fragen.
- Kategorien unterstützt.
- Auswertung nach Abschluss.

### Kategorien

- Folgen.
- Ermittler:innen & Teams.
- Drehorte & Städte.
- Schauspieler:innen.
- Kriminalistik.
- Geschichte.
- Allgemeinwissen.

## Memory

### Motive

- Fingerabdrücke.
- Tatorte.
- Ermittler:innen.
- Polizeimarken.
- Spurensicherung.
- Beweismittel.
- Teams.

### Schwierigkeitsstufen

| Stufe | Spielfeld |
|---|---|
| Leicht | 4×4 |
| Mittel | 6×6 |
| Schwer | 9×9 |
| Experte | 12×12 |

## Rangliste

### Zeiträume

- Heute.
- Diese Woche.
- Insgesamt.

### Anzeige

- Rang.
- Avatar.
- Alias.
- Mitwisser-Level.
- XP.
- Veränderung zum vorherigen Ranking.
- Eigener Rang hervorgehoben.

## Anti-Spam-Regel

Gamification darf kein Spam-Verhalten belohnen. Chat-XP und Reaktions-XP müssen gedeckelt oder gewichtet werden.
