# Memory-Motive (Noir-Icons)

50 quadratische Motive für das Spurfunk-Memory (`memory_01` … `memory_50`).

## Einzelnes Motiv austauschen

1. Neue PNG **gleichen Dateinamens** hier ablegen (z. B. `memory_03_lupe.png`).
2. Optional Noir-Grading anwenden:
   ```bash
   python3 tool/postprocess_tatort_asset.py portrait \
     neue_datei.png assets/photos/memory/memory_03_lupe.png
   ```
3. App neu starten (Hot Restart reicht für Assets).

Die Zuordnung Label ↔ Datei steht in `lib/features/community/data/memory_motifs.dart` (`MemoryMotif.assetFileName`).
